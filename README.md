# DIKWP FUTURECRAFT / XINGZHOU 16.0.0

Created by Yucong Duan (段玉聪).

> Do not predict one stable job. Build stability that remains portable across futures.

`XINGZHOU16_REAL_PROBLEM_LEARNING_CONTINUITY_ASSET_PORTFOLIO_MULTI_WORLD_EVIDENCE_PIVOT_CLOSURE`

XINGZHOU is a local-first education innovation and career-continuity client. It replaces one-shot betting on a degree, examination or job title with:

```text
Purpose and protected floors
→ plural futures
→ reversible path portfolio
→ real-problem mission
→ just-in-time learning
→ evidence ledger
→ week 4/8/12 decision gates
→ Career Continuity Passport
→ reality contact and reconfiguration
```

It is not a career personality test, job-ranking engine, admission predictor or employment guarantee.

## Demo case

For the bundled business-administration student, the default portfolio is:

- 20% public-sector examination hedge;
- 20% AI-enabled operations and governance capability;
- 60% real-problem mission;
- 0% postgraduate path until programme, supervisor, research problem, curriculum and capability gain are made specific and testable.

The percentages are editable planning recommendations, not calibrated forecasts or judgements of human worth.

## Quick start

Open the standalone client:

```text
release/XINGZHOU_Client_16.0.0.html
```

No server, account, model API, database or network is required.

Run the source client by opening `index.html`, or:

```bash
python -m http.server 8760
```

CLI:

```bash
node tools/run_xingzhou.mjs examples/business_admin_student.json --out outputs/runtime
```

Tests:

```bash
npm test
```

## Core functions

- continuity dashboard;
- student purpose and protected floors;
- plural future worlds;
- reversible path-portfolio engine;
- 12-week real-problem mission builder;
- just-in-time learning map;
- local evidence receipt ledger;
- week 4/8/12 continue/pivot/stop gates;
- JSON/HTML Career Continuity Passport.
